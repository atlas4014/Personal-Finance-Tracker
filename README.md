# 💰 Personal Finance Tracker

> My first "real" project — built while learning backend development, and honestly, while learning how much I *don't* know yet.

## About This Project

This is a simple web app that helps you track your income and expenses — nothing fancy, just something I built to actually understand how a backend talks to a database, instead of just reading about it.

I started this because I wanted to move past tutorials and build something I'd actually use myself. Turns out, tracking your own spending is a great way to learn CRUD operations *and* realize how much you spend on food delivery.

This project taught me:
- How a Flask app is structured (routes, templates, logic — the whole flow)
- How to design a MySQL database schema that actually makes sense
- How to connect a web app to a database and keep data persistent
- That "it works on my machine" and "it works" are two very different things
